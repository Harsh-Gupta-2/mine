## Diagrams and Limits

The original no-download restriction was relaxed for diagram dependencies only. The installed Mermaid 11.12.0 bundle is kept locally under vendor/mermaid with its license and provenance notes. The builder reuses VS Code's Node runtime and installed Chrome, with network requests blocked during diagram rendering. It does not download anything during a rebuild. Pandoc/Mermaid CLI are not used; the Markdown-subset publisher and local browser renderer provide the offline publication.

**All 42 diagrams across Chapters 00-04 are rendered as inline SVG.** Wide diagrams scroll within the reader and open at natural size in an expanded view; narrow diagrams are not stretched. Mermaid source remains collapsible and copyable. Diagrams use a white canvas in both themes and fit the print layout. Reading the HTML or PDF requires no server, CDN or network. **Syntax highlighting remains unavailable.**

Java source is under code/ for Chapters 01-04; all runners recorded NOT EXECUTED. No JDK, Maven or cached Java dependencies are available. Maven runners use offline mode; the diagram approval does not authorize downloading Java tooling or libraries. No Java/Spring/Hibernate output is claimed. Publication checks validate listing/source consistency separately from Java execution.

## Rebuild

Windows PowerShell, from the workspace root, no administrator privileges required:

```powershell
& './docs/java-fs-guide/build.ps1'
& './docs/java-fs-guide/build.ps1' -Test
```

Both commands were executed locally. The first emits HTML and PDF; the second checks the built HTML, diagrams, source contracts, and reciprocal links. `-HtmlOnly` skips PDF printing but still uses Chrome for uncached diagrams. The actual build report is [dist/build-report.json](dist/build-report.json).

With an independently available Node 22+ runtime, `npm run build` and `npm test` are also defined, but those exact npm commands were **not executed** here because standalone npm is unavailable. No dependency installation is required. The fallback parser deliberately supports only the Markdown constructs used in the written chapters; do not assume arbitrary future Markdown works without tests.

Chrome uses a disposable profile below `.build/`, not the user's browsing profile. The script does not download anything or change system-wide PATH. Set `GUIDE_CHROME` to another installed Chromium executable when needed.
